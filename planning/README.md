# ControlWash Delivery Planning

This folder translates the canonical product specifications into a delivery
sequence. Specifications define behavior; planning files organize work and do
not override the specifications.

- [Decision log](DECISION_LOG.md)
- [User stories](USER_STORIES.md)
- [Delivery plan](DELIVERY_PLAN.md)
- [Domain model](DOMAIN_MODEL.md)
- [API plan](API_PLAN.md)
- [MVP acceptance scenarios](MVP_ACCEPTANCE.md)

Before implementing a story, confirm its specification, acceptance criteria,
tenant/Branch scope, permissions, ledger effects, and reversal behavior. A story
is done only when code, tests, translations, and affected documentation agree.
